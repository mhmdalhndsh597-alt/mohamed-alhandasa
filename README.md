# مراقبة السيولة — وضع القراءة فقط

هذا المستودع يحتوي على مراقب **للقراءة فقط** لعقود وشبكات البلوكشين. لا يوقّع معاملات، ولا يرسلها، ولا يسحب أرباحًا، ولا يتحكم في محفظة باردة. أي تحويل فعلي يجب أن يتم خارج GitHub Actions عبر محفظة باردة أو Safe متعدد التوقيعات وبعد مراجعة بشرية.

## ما يفعله

- يتحقق من الشبكة ورقم آخر كتلة عبر RPC.
- يسجل لقطة مراقبة قابلة للتدقيق.
- يرسل تنبيهًا محدودًا إلى Discord عبر Webhook اختياري.
- يفشل مغلقًا عند تعطل RPC أو اختلاف الشبكة.
- يشغل اختبارات وفحوص `ruff` و`bandit` و`pip-audit` في GitHub Actions.

## متغيرات GitHub

ضع القيم العامة التالية في **Actions Variables**:

- `CHAIN_ID`
- `WATCH_ADDRESSES`
- `CONTRACT_ADDRESSES`

ضع القيم التشغيلية غير العامة التالية في **Actions Secrets**:

- `RPC_URL`
- `DISCORD_WEBHOOK_URL`

لا تضف أبدًا مفاتيح خاصة، seed phrases، رموز وصول لمحافظ، أو مفاتيح توقيع إلى هذا المستودع أو GitHub Actions أو Discord. لا توجد في المشروع دالة توقيع أو إرسال معاملات.

## التشغيل المحلي

```bash
export RPC_URL="https://your-read-only-rpc.example"
export CHAIN_ID="1"
python monitor.py
```

## حدود النطاق

أوامر Discord للتحويل أو التوقيع أو تشغيل/إيقاف معاملات مالية غير مدعومة. Discord هنا قناة تنبيه فقط، مع `allowed_mentions` معطلة لتقليل مخاطر الإزعاج أو الإشارات غير المقصودة.
